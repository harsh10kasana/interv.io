# Interv.io 

An AI-powered mock interview platform designed to help users practice real-time interviews, receive dynamic follow-up questions, and track their performance. 

## Features

* **Secure Authentication:** Seamless and robust Google Sign-In powered by Firebase (bypassing strict browser popup blockers using a redirect flow).
* **Role-Based Simulation:** Adaptive interview difficulty based on the selected job role.
* **AI Intelligence:** Dynamic, real-time follow-up questions based on user responses (In Progress).
* **Modern UI:** Clean, responsive, and professional dashboard interface.

##  Tech Stack

* **Frontend:** React.js, Vite, Tailwind CSS, React Router, Framer Motion
* **Backend:** Node.js, Express.js (REST API)
* **Authentication:** Firebase Auth
* **State Management:** React Context API
